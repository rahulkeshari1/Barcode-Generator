Try the application online:

### 👉 https://barcodemaker.shop

---

## 📌 About The Project

**Barcode Generator** is a web-based tool designed to make barcode and QR code generation simple and accessible.

The application provides a clean interface where users can enter their required information and generate machine-readable codes that can be downloaded and used for different purposes.

The project is built with modern frontend technologies and is optimized to work across desktop and mobile devices.

---

## ✨ Features

### 🔳 Barcode Generator

* Generate barcodes from text or numbers
* Quickly create printable barcodes
* Download generated barcodes
* Simple and user-friendly interface

### 📱 QR Code Generator

* Generate QR codes from text
* Generate QR codes from URLs
* Generate QR codes for different types of information
* Download generated QR codes
* Fast client-side generation

### 🎨 User Interface

* Modern responsive design
* Desktop and mobile support
* Clean and simple interface
* Easy navigation
* Fast interaction
* Browser-based generation

## 💻 Installation

### 1. Clone the repository

```bash
git clone https://github.com/rahulkeshari1/Barcode-Generator.git
```

### 2. Open the project

```bash
cd Barcode-Generator
```

### 3. Install dependencies

```bash
npm install
```

`node_modules` is intentionally not included in the GitHub repository.

It is automatically generated when you run:

```bash
npm install
```

---

## ▶️ Run Development Server

Start the Vite development server:

```bash
npm run dev
```

You should see an output similar to:

```text
Local: http://localhost:5173/
```

Open the displayed URL in your browser.

## 🚫 Files Excluded From GitHub

The following files/directories are intentionally excluded:

```text
node_modules/
dist/
dist-ssr/
dist.zip
.env
.env.*
*.log
.vscode/
.idea/
```

### Why isn't `node_modules` included?

The `node_modules` directory contains installed dependencies and can become very large.

Dependencies are defined in:

```text
package.json
package-lock.json
```

Anyone cloning the repository can recreate `node_modules` using:

```bash
npm install
```
